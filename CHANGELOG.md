# Changelog

Mudanças de cada versão do Tilim. O texto de cada versão vira a descrição da Release no GitHub.

## 1.6.1 — 2026-10-17

### Correções
- **Sempre dá para parar o alarme**: se o alarme estiver tocando e você abrir o Tilim, ele já mostra a tela com os botões **Parar** e **Adiar**.
- Se o aviso do alarme for arrastado para o lado ou apagado sem querer, ele volta sozinho, até você tocar em **Parar** ou **Adiar**.

## 1.6.0 — 2026-10-10

Primeira versão publicada no GitHub.

### Novidades
- **Atualização pelo próprio app**: quando sai versão nova, aparece "Chegou uma versão nova do Tilim" com o botão **Atualizar agora**. O Tilim baixa a versão nova e abre o instalador.
- **Preparação passo a passo**: as permissões agora aparecem uma por vez ("Passo 1 de 3"), em letra grande, dizendo antes o que vai aparecer na tela e qual botão tocar.
- Agenda e notificações são pedidas num toque só.
- Os passos opcionais (bateria e "Não perturbe") têm o botão "Pular esta parte".

### Importante para quem já usa
- A partir desta versão, o app é assinado com a chave oficial. **Desinstale o Tilim antigo antes de instalar este.** Os compromissos não se perdem, porque ficam no Google Agenda. Só os ajustes (avisos padrão e toque escolhido) voltam ao padrão.
